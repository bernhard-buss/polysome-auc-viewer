Excel export: a Summary tab (settings + all AUCs/ratios) plus one tab per sample with the trace data and a native Excel chart.
AUC = trapezoidal integral of baseline-corrected OD over the region (units: OD·mm). The ratio is unitless and independent of loading and path length as long as both regions come from the same trace. Method: baseline per trace by the rule chosen above; identical region boundaries for every trace.
Baseline options — the value subtracted from the curve before integrating:
• flat — minimum inside regions (default): the lowest OD between the monosome start and the polysome end, per trace. Robust when the trace has a flat valley inside the regions; assumes the background is constant across the gradient.
• linear — between curve at region edges: a straight line from the curve value at the monosome start to the value at the polysome end (a “chord”). Use when the background visibly drifts upward along the gradient (e.g. rising absorbance toward the bottom) — but note it goes negative wherever the curve dips below the chord.
• none: integrate the raw OD. Only comparable across samples if all traces share the same offset.
The choice matters more than the integration itself — pick one, keep it for every sample in a comparison, and report it (the CSV export records it).
Tips: multi-sample “paste-up” CSVs (e.g. PT_CON_1.csv) put every sample on the first sample’s position grid — the single-trace exports are the accurate source, so prefer those. The duplicated readings around 0 mm are an instrument quirk (position reset at meniscus detection); keep the monosome start well above that region. The “fit y-axis” toggle only zooms the display to the mono/poly regions — it never changes the numbers. Align traces at the monosome peak: runs from the same session can be offset against each other by 2–4 mm (meniscus-detection variance), which slides peaks across fixed region boundaries and can make replicates disagree. This option shifts each trace so its tallest peak near the monosome window (±3 mm; the artificial instrument spike at the gradient top is ignored) sits at the shared median position (the applied shift is reported per sample and in the CSV); regions are then applied to the aligned positions. Place the monosome window roughly over the 80S peak first, then turn this on whenever the overlaid peaks visibly do not line up.
